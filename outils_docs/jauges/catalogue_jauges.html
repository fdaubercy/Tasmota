Mon conseil

D (coupe de la cuve) pour la page d'accueil : à l'échelle, en litres et en cm, sans librairie, et la valeur se substitue directement dans le gabarit par vos #…#. F ou G si la place manque. E est le plus joli, mais la page d'accueil de Tasmota remplace ce bloc toutes les ~2 s : la vague repart de zéro à chaque fois (c'est vrai aussi pour l'ondulation de D, qu'on peut retirer).

A, B et C ne s'exécutent pas dans le bloc de la page d'accueil (un script inséré là n'est pas lancé). Ils se justifient sur une page dédiée ; B est alors le plus économique, ECharts étant déjà sur les cartes qui ont /graphiques.

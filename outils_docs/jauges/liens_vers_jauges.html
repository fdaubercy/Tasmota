Lien vers les jauges de la cuve

Huit façons d'annoncer la page /cuve dans l'encadré « Capteurs de Niveau de Cuve » de l'accueil. Chaque maquette reproduit l'encadré à sa largeur réelle (340 px), avec des valeurs d'exemple. Toutes tiennent dans le gabarit tel qu'il est : du HTML et du CSS seuls, sans script (la zone des capteurs est remplacée toutes les 2 s). Survole les liens pour voir leur réaction, puis donne-moi la lettre retenue.

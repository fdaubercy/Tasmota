Portail C : le portail comme un volet roulant à paramétrer



Même bouton, même cible : un appui pendant le mouvement arrête le portail, un second appui le fait repartir vers la même cible. Un autre bouton change de cible. Position 0 à 50 % : le vantail droit pivote ; 50 à 100 % : le gauche prend le relais ; au retour, le gauche se ferme d'abord. Chaque vantail démarre et s'arrête en douceur.
